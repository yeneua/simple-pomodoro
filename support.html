자주 묻는 질문

화면이 꺼져 있어도 끝나면 알려주나요?

네. 시작할 때 종료 시각에 알림을 예약해 둡니다. 처음 시작할 때 알림 권한을 허용해 주세요. 놓쳤다면 설정 → 알림 → SimPo에서 켤 수 있습니다.

소리가 안 나요.

무음 모드에서는 소리 대신 진동만 울립니다. 기기 옆 무음 스위치나 제어 센터를 확인해 주세요.

시간을 직접 입력할 수 있나요?

첫 화면의 숫자를 누르면 키패드가 나옵니다. 1~180분까지 설정할 수 있습니다.

플립 시계와 다이얼은 어떻게 바꾸나요?

타이머가 도는 중에 화면을 한 번 누르면 버튼이 나타납니다. 모드 전환, 라이트/다크 테마, 일시정지, 처음으로 버튼이 있습니다.

FAQ

Will it alert me when the timer ends, even with the screen off?

Yes. When you start a timer, SimPo schedules a notification for the end time. Allow notifications the first time you start a timer. If you declined, you can turn them on in Settings → Notifications → SimPo.

I don't hear a sound.

In silent mode the alert only vibrates. Check the silent switch (or Action button) and Control Center.

Can I type the minutes directly?

Tap the number on the first screen to open a keypad. You can set anywhere from 1 to 180 minutes.

How do I switch between the flip clock and the dial?

Tap the screen once while the timer is running to show the controls: switch mode, light/dark theme, pause and reset.
